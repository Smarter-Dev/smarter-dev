Retention Policy

Help conversations are Discord message content, so they live on the same 48-hour window as every other passively captured message text. An hourly sweep blanks the question, the answer and the surrounding channel context, leaving the row's timestamps, token count and latency for usage reporting.

The standard / minimal / sensitive tags above are labels only — they no longer select different windows.
