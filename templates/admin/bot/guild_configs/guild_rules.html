Rules Document

The /rule command quotes one of these rules at a message, so every rule needs its own number. Numbering is automatic — it comes from the order below.

How to write the rules
  • Start each rule with a markdown heading holding its short title: ## No self-promotion.
  • Everything under that heading, until the next heading, is the rule's body. Blank lines, lists and **bold** are all fine.
  • Every markdown heading starts a new rule, so do not use headings inside a rule's body — use bold text or a list instead.
  • Text above the first heading is an intro, not a rule. It is ignored by /rule.
  • Rules are numbered from 1 in the order they appear, so reordering them renumbers them. Do not number the headings yourself.
  • A heading with nothing under it is still a rule — a title with an empty body.
